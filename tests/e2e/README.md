# calibrat3 end-to-end tests

Real-browser (headless Chromium via Playwright) tests that drive the actual app and
assert on runtime state (`window.__calibrat3.state`). They exercise what the DOM-less
unit tests cannot: WebCodecs decoding, the worker pool, OpenCV.js in workers, the
WASM bundle adjuster, and the UI wiring.

The app has **no build step**; this directory is a self-contained harness with its
own `package.json`. `node_modules/` here is git-ignored.

## Setup (once)

```bash
cd tests/e2e
npm install                              # playwright
npx playwright install chromium          # browser
npx playwright install-deps chromium     # Linux system libs (or apt-get libnss3 libnspr4 libatk… )
```

## Run

From the **repo root**, start the static server, then run a test:

```bash
python3 server.py 8080                       # terminal 1
node tests/e2e/smoke-pipeline.mjs            # terminal 2
```

Environment: `BASE=http://host:port` (default `http://localhost:8080`),
`TARGET=<samples>`, `SCREENSHOT=path.png`, `VERBOSE=1` (echo page console),
`HEADFUL=1`. Exit code `0` = pass.

## Tests

- **`smoke-pipeline.mjs`** — sample session → batch detection → intrinsics →
  extrinsics → bundle adjustment → TOML preview → hotkey navigation/exclusion.
  Fails on any page error or `console.error`, and on out-of-range results
  (intrinsic RMS ≥ 5 px, cross-view median ≥ 10 px, SBA cost not reduced).
- **`stress-synthetic.mjs`** — opens a long synthetic session generated by
  `scripts/make_synthetic_session.py` (default 4 cameras × 1200 frames, anipose-style
  folder layout) through the `webkitdirectory` fallback input, detects on
  every frame, runs intrinsics/extrinsics/SBA, compares against the generator's
  ground-truth `calibration.toml`, and reports wall-clock timings. Requires
  `SESSION=/path/to/synthetic_session`.
